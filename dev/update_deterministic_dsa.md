## Implementation requirements

Refactor `code/10_deterministic_dsa.R` only as much as necessary so that it performs deterministic sensitivity analyses against the **current model structure produced by `code/00-08*`**.

The DSA should:

- start from the appropriate current saved baseline/calibrated/model artifacts already on disk;
- use the current intervention definitions and scenario architecture;
- use current parameter names, objects, causes, ages, sexes, locations, years, and model conventions;
- perturb only the intended DSA parameters/assumptions;
- rerun only the downstream calculations actually required for each deterministic sensitivity scenario;
- avoid repeating expensive upstream preprocessing or calibration;
- produce clearly labeled baseline and sensitivity results;
- preserve reproducibility;
- avoid hard-coded legacy assumptions when the corresponding values can be obtained from the current pipeline objects/configuration.

Where the current `00-08*` pipeline already provides functions or objects needed to run scenarios from saved calibrated inputs, reuse them rather than duplicating model logic.

Do not introduce a new modeling algorithm.
